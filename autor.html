Sobre mí

Soy Alfredo Peters y curso la asignatura Desarrollo de Software V. Como parte del curso, trabajé en el diseño y la programación de este sitio en Visual Studio Code.

Elegí la inteligencia artificial aplicada al desarrollo de software. Aquí explico cómo puede ayudar al programar y uso un ejemplo de una lista de tareas para mostrar por qué conviene probar el código antes de usarlo.

Sobre el sitio

Las páginas se elaboraron con HTML, CSS y JavaScript. El diseño utiliza estilos propios y una organización común para facilitar la lectura y la navegación.

Para recorrer el contenido, utiliza los enlaces del menú. En una pantalla pequeña, pulsa «Menú» para mostrar u ocultar los enlaces. También puedes cerrarlo con la tecla Escape.
